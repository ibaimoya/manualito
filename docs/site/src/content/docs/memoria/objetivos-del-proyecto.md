A continuación, se detallan todos los objetivos que se persiguen con el desarrollo de *Manualito*.

## Objetivos generales

<div id="objetivos:generales"></div>

El proyecto persigue los siguientes objetivos generales, que se desarrollan en la especificación de requisitos del Anexo B:

- Desarrollar una aplicación web que facilite el aprendizaje y la consulta de las instrucciones y reglas de juegos de mesa.
- Procesar manuales en distintos formatos para extraer su contenido y utilizarlo dentro de la aplicación.
- Generar explicaciones y responder preguntas sobre un juego a partir de la información contenida en sus manuales.
- Almacenar de forma organizada la información de los juegos, los manuales y las conversaciones de cada usuario para permitir su consulta posterior.
- Proteger las cuentas y la información de los usuarios frente a accesos y modificaciones sin permiso.

## Objetivos técnicos

<div id="objetivos:especificos"></div>

Se plantean los siguientes objetivos técnicos:

- Integrar técnicas de OCR para extraer y preparar el texto de los manuales.
- Diseñar un sistema RAG que combine búsqueda léxica y semántica para fundamentar las respuestas del modelo.
- Integrar modelos de lenguaje ejecutados localmente mediante Ollama.
- Desarrollar la interfaz con React y TypeScript y el servidor con FastAPI.
- Aplicar una arquitectura modular y patrones de diseño que faciliten el mantenimiento.
- Utilizar PostgreSQL para la persistencia y ChromaDB para la búsqueda vectorial.
- Gestionar las tareas de procesamiento en segundo plano mediante Celery y Redis.
- Preparar un despliegue reproducible mediante Docker Compose y gestionar la infraestructura con Terraform.
- Utilizar Git con GitHub y GitLab para el control de versiones.
- Automatizar las pruebas y el análisis de calidad mediante integración continua, y publicar la parte estática mediante despliegue continuo.
- Evaluar las distintas tecnologías del sistema mediante pruebas de rendimiento.

## Objetivos personales

<div id="objetivos:personales"></div>

Además de mencionar los objetivos generales y técnicos, se presentan los objetivos a nivel personal que me han llevado a desarrollar este proyecto:

- Adquirir conocimientos de tecnologías y arquitecturas del campo de la inteligencia artificial.
- Comprender el ciclo de desarrollo y despliegue de una aplicación web.
- Mejorar la capacidad para planificar y organizar un proyecto de desarrollo.
- Profundizar en el diseño y desarrollo de interfaces de usuario.
- Explorar el desarrollo agéntico [[8](https://www.ibm.com/think/topics/agentic-coding)] como apoyo en tareas concretas del proyecto.
