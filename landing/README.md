# Landing de Manualito

Página pública de `manualito.dev`, con acceso a `app.manualito.dev`.
HTML, CSS y recursos locales. No necesita JavaScript ni compilación.

Para verla en local, desde esta carpeta se puede ejecutar
`python -m http.server 5228 --bind 127.0.0.1` y abrir `http://127.0.0.1:5228`.

Las licencias de las fuentes están en `assets/licenses`.
